# Temperaturas-en-NY-
El proyecto buscó modelar y pronosticar la temperatura promedio anual de Nueva York entre 1870 y 2020, usando el 90% de los datos para entrenar y el 10% restante (2005-2020) para probar. Tras comprobar con la prueba Dickey-Fuller que la serie original no era estacionaria y que una diferenciación bastaba para lograrlo, se compararon 12 modelos ARIMA mediante el criterio AIC y se eligió el ARIMA(3,1,3). Sus pronósticos tuvieron un error promedio de poco más de 1 °F, y el 100% de los valores reales quedó dentro del intervalo de confianza del 95%, lo que indica una buena precisión y calibración. Sin embargo, las predicciones se mantuvieron casi planas alrededor de 55 °F, por lo que el modelo no logra reflejar del todo la tendencia de calentamiento reciente.
